# Fuentes históricas preservadas

Esta carpeta conserva el perfil original, los ocho documentos principales, sus cinco láminas y documentación técnica del repositorio antecedente. Son fuentes históricas y no requisitos vigentes. No ejecutar sus instrucciones sobre la base actual ni confundir sus capacidades propuestas con la reformulación.

La restricción vigente excluye hardware externo y lockers inteligentes. Consultar el [proyecto reformulado](../../README.md) y la [matriz de correspondencia](../../docs/gestion/01_decisiones_y_correspondencia.md).

El [manifiesto de integridad](../manifest_fuentes.json) identifica 19 fuentes con su origen, copia y SHA-256. El README raíz antecedente se conserva como [README_PROYECTO_ORIGINAL.md](README_PROYECTO_ORIGINAL.md). Los libros comerciales no se incluyen: se documentan fuentes públicas en la bibliografía.
