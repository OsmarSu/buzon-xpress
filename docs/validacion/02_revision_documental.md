## Límites de la revisión

Las comprobaciones de OpenAPI son de estructura, rutas y referencias locales; no se ejecutó un validador normativo completo. El SQL se examinó estructuralmente, sin un servidor PostgreSQL aislado disponible para ejecutarlo. Las treinta pruebas de producto permanecen pendientes. Se inspeccionaron visualmente las láminas principales y muestras de los PDF exportados.

La bibliografía diferencia fichas editoriales, recursos de autores y extractos; no se declara lectura integral de libros comerciales. Las fuentes originales se conservaron sin cambios.
